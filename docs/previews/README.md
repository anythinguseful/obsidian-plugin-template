# Previews

Optional **static** mockups (HTML/SVG) that illustrate a settings card or panel without running Obsidian.

Rules:

- Inline CSS only if this file will be opened in a no-network preview.
- A mockup that states where a control lives **must** be updated in the same commit as the real settings move, or deleted with a pointer to the new location.
- Generated screenshots and Playwright output do **not** belong here — they are ignored artifacts (`preview/`, `test/`).
